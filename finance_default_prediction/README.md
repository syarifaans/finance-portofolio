# Finance Default Prediction

## Project Overview
This project predicts whether a customer will default on their credit card payment using financial and demographic data.  
The analysis includes data cleaning, exploratory data analysis (EDA), feature engineering, machine learning models, and model interpretability.

## Dataset
- Source: [Default of Credit Card Clients - Kaggle](https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset)
- Rows: 30,000+  
- Features: Demographics, financial history, credit limit, payment status  
- Target: Default payment (Yes/No)

## Goals
- Perform data cleaning and exploratory data analysis (EDA)
- Build baseline models (Logistic Regression, Decision Tree)
- Improve performance with advanced models (XGBoost, LightGBM)
- Interpret results using SHAP values
- Deploy results in an interactive dashboard
