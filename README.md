# Default Prediction on Credit Card Clients

## Project Overview
This project predicts whether a customer will default on their credit card payment using financial and demographic data.

## Dataset
Source: [Kaggle - Default of Credit Card Clients](https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset)

## Goals
- Explore dataset and clean it
- Build baseline machine learning model
- Improve with advanced models (XGBoost/LightGBM)
- Interpret results with SHAP
- Create dashboard for visualization
